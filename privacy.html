Privacy policy

Last updated: November 18, 2026

Who uses Jarvis

Jarvis is a personal home assistant used only by its owner's household. It is not offered to the public.

What Google data Jarvis accesses

With the owner's permission, Jarvis uses Google's Smart Device Management API to read and change the settings of the Nest devices the owner selects: for example the indoor temperature, humidity, thermostat mode, Eco mode, fan and target temperature. Google may also share the home's name, room names and zip code.

How the data is used

The data is used only to show the owner the state of their own devices and to carry out changes the owner asks for. It is not used for advertising, profiling or any other purpose.

Where the data is kept

Jarvis runs on the owner's own computer. Device readings and the sign-in token Google issues are kept on that computer only. Nothing is stored on servers run by anyone else.

Sharing

Jarvis does not sell, rent or share Google user data with anyone. Data is sent only between the owner's computer, the owner's own devices, and Google.

Google API Services User Data Policy

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account's Third-party connections page or from the Google Home app. Removing access stops Jarvis from reading or changing any Nest device, and the owner can delete the stored token from their computer.
